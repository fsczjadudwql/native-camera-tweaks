## Overview

Native Camera Tweaks extends Baldur's Gate 3's camera beyond its default limits, allowing deeper zoom-out for tactical overview, increased pitch range for cinematic angles, faster rotation speed, and per-mode camera presets for combat versus exploration. All settings are configured via a simple JSON file with no external dependencies.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Native Camera Tweaks** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Extended Zoom** | Zoom out further than the vanilla camera limit for better tactical view |
| **Full Pitch Range** | Tilt the camera to extreme angles for cinematic screenshot compositions |
| **Rotation Speed** | Configurable camera rotation speed for mouse, keyboard, and controller |
| **Preset Profiles** | Save different camera configurations for combat and exploration modes |
